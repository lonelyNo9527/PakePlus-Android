壹游戏概览

《云隐修仙录》是一款开源的文字版水墨修仙放置游戏：竖版排版、移动端优先，玩家从一缕游魂开始，历经炼气至真仙十大境界，在程序生成的「本世之界」中历练、结缘、渡劫，寿元耗尽后携道果宿慧转入下一世，直至踏入真仙终局的天界规则宇宙。游戏没有体力值和付费点，核心循环是「修炼 → 历练 → 突破 → 转世 → 更快地修炼」。

贰快速上手

开始游戏

三个渠道任选其一：

  • 网页直接玩：打开 yunyin.wenzi.games，浏览器即点即玩，进度自动保存在本机；
  • Windows 桌面版：到 GitHub Releases 下载最新的 yunyin-x.x.x-win.zip，解压后运行即可（数据与网页版相互独立）；
  • Android 版：同样在 Releases 页下载 APK 安装。
放心挂机：游戏没有体力值和付费点，关掉页面也不断收益——回来时按离线时长统一结算（详见离线与存档）。

开局流程

  1. 欢迎页（隐私同意）→ 捏人页：随机生成灵根，可「逆天改命」重掷，上限 8 次；
  2. 灵根一旦定下便奠定本世修速倾向与天劫解法，详见灵根系统；
  3. 入世后从炼气一层开始：底部五页签——洞府、修炼、历练、背包、人物，便是最常用的主界面；
  4. 修炼页挂机涨修为，历练页派人出门杀敌掉装备，攒满修为回修炼页突破——这三步构成前几个小时的全部节奏。
捏人时别追求「全灵根」：根数越少成长倍率越高，单根天灵根（≥80 资质）的成长甚至超过五根杂灵根。重掷上限 8 次，前 2~3 次抽到单根或双根就可以收手——灵根主要影响功法与机缘契合，是倾向不是门槛。
机制提示：寿元按真实时间流逝——每 1 现实小时涨 1 岁（起始 16 岁），年龄到达寿元上限即死亡进入转世。离线时寿元照常流逝（不受离线收益封顶约束），挂机与放置本身就是这一世的寿命。

这一世是怎么过去的

  • 每秒：天时变化 → 修为增长 → 灵气恢复 → 建筑产出 → 探索推进 → 顿悟判定 → 寿元流逝；
  • 每 30 秒：每日任务重置、状态型成就检查、洞府巡游事件；
  • 关掉页面再回来：按离线时长一次性结算收益，弹出「归来」面板（详见离线与存档）；
  • 寿元尽：转入轮回，带着道果与宿慧开始下一世（详见转世与轮回）。

肆工具与存档

设置页内置存档导出/导入：设置 → 存档，导出得到 yunyin-xiuxian-日期.save 文件，换设备或重装前先导出一份，再在新环境导入即可无缝续玩。

进阶工具（谨慎使用）：本站附带一个本地存档修改器，可以直接改灵石、修为、装备、成就等。修改存档会严重破坏游戏体验，且改坏了档无法恢复——请先导出留底，想清楚再进。
