壹转世与轮回

触发与流程

  • 主动兵解：金丹境起可随时转世；寿元耗尽（年龄 ≥ 寿元）自动死亡进入转世。
  • 转世流程：结算单（本世境界/寿元/命题结局/宿慧）→ 三选一天赋 + 额外 floor(大境/2) 项 → 选下一世命题 → 重掷灵根与本世之界 → 转生。

保留 / 失去

保留（跨世不灭）清空 / 折损
道果、天赋、宿慧与历世履历、认知图鉴（灵材/丹方/技艺/敌人）、灵脉点数、成就、师承、道源与道痕、修行节点与纪录、关系历史灵石/灵气/悟道点/灵草/玄铁/残页/器灵尘全部归零；装备/丹药/法宝全失；功法层数折半（百世老修阶可留最深一门）；建筑等级折半；历练解锁重置；本世之界重掷；道途重选；灵根资质重掷（地板 = max(次数×5, 宿慧÷12)）

道果

道果所得 = Σ(i=1..大境序号+1) i×3 + floor(小层/3)
有效道果 = 道果^0.9        # 软上限、次线性但无界
每颗有效道果：修速 +3%，战力 +1.5%

金丹圆满一世 = 21 枚道果——设计上明确承认：道果效率最优点在金丹——耗时按约 3.3 倍/境界指数增长，而道果只有二次增长，「金丹作为最快的道果农场予以承认」。道果没有消费出口：不解锁天界、不换任何东西，是纯粹的永久成长（速度项直接闭环「更快→更早轮回→更多道果」）。

宿慧与轮回阶

宿慧 = 存量（历世阅历 + 已达成命题）+ 现量（认知折算：认得灵材 +3、通晓再 +5；通晓丹方 +4；技艺熟练度和 ÷20；洞悉敌人 +2）。轮回阶「每一阶开的是『知道什么』，不是『加多少』」——一分属性不加：

阶名称所需宿慧能力
0初入轮回0—
1熟知凡间90睁眼即识 2 阶以下灵材
2熟知修仙界260即识 4 阶 + 战前见敌人机制
3熟知天界600即识 6 阶 + 天数可窥（天劫与终局规则细节提前可见）
4百世老修1100即识 9 阶 + 命题自选 + 留一门功法不折半

人生命题（15 种）

每世可立一题：立题（vow）+ 禁忌（如服食丹药、祭用法宝，犯之即「破题」，当场判定、不扣任何东西）+ 判据（全部按「本世」计）。达成得宿慧（如结丹 22、踏遍山川 24、识百草 26）。结局三种：践行到底 / 未竟 / 已破。命题按轮回阶开放，顶阶自选、其余抽三取一，走到底的题不再出现。

转世时机：金丹境转世性价比最高——道果已初见规模、单境耗时又短，是公认的「农场」节奏；卡在大关突破时果断兵解，比硬耗寿元更有效率。宿慧攒到 90 以上跨入第二轮回阶，下一世的新手期会快一截。

贰本世之界

每次转世（兵解）都程序化重组一个「本世之界」——用现有素材（20 区域/60 敌人/8 类 Boss 机制/51 事件）生成「这一世不一样」的凡界。区域从静态素材库变为按本世路线节点组织；唯一换界时机是转世。

世界生成

  • 路线骨架（7 种）：短促 / 匀进 / 长尾 / 前缓后陡 / 前陡后缓 / 深浅交错 / 短程交错——决定每段地界的层级跳跃；
  • 事件节奏（6 种）：平稳 / 前紧后松 / 前松后紧 / 中段高压 / 双峰 / 终局堆积；
  • 资源偏向（5 种）：草木丰饶 / 矿脉深厚 / 典籍散佚 / 灵石充盈 / 药气氤氲；
  • 此世规则：从 8 条天道变数中取 1 条笼罩本世（如「生机断绝」治疗 −75%）；
  • 每段地界按就近层级取 3 个小妖 + 1 个首领（全世去重），按节奏曲线定事件密度。

四门验收（mortalGate）

候选世界须过四道互相独立的门（「不可用综合分数掩盖关键维度缺失」）：①结构新颖度 ≥0.25（首领机制/敌人/事件加权 Jaccard）；②可行构筑 ≥3 且最强构筑胜率 ≤0.97；③路线骨架新颖度 ≥0.30；④事件节奏差异 ≥0.30。另有「首领生态」一票否决。任一门不过即换种子重来（最多 300 次）。

世界身份按地貌轴（山岳/林泽/火域/天象/废墟/幽冥）+ 规则主题命名：「生机断绝的山岳之世」「X 与 Y 交错之世」等。可达性只追加不收回——已通段落仍可再去。

叁机缘链与机缘回响

  • 机缘链：「机缘不只是中奖：选择被记录，影响未来。」每次事件判定 2% 概率改判机缘事件（灵根同源权重加成）；你的每次选择记为 take（选非默认）/ leave（选默认）；机缘内容会向契合的师承「顺水推荐」（如剑痕机缘 → 剑修拜师高亮）。
  • 机缘回响：「世界认识你。」曾放弃的机缘再遇时有 5% 概率化作回声叙事（认出你 / 缘分已尽 / 留下痕迹）——「竹屋前的老人抬眼望来……『原来是你。』」边界锁死：只读选择记录，不产出任何资源属性。

肆真仙终局总览

突破真仙后解锁天界（/celestial）。天界的核心命题是：数值成长在天界互相抵消，只有构筑形状决定胜负——装备词条按「器魂容量 1.3」归一，超出基准（2.6）部分敌人同步加厚，「九件神品与三件精品方向相同即为同一构筑」。

陆远征与试炼

  • 路线远征：入界战 → 三层二择路 → 界主，共 5 场；携带血量、场间回复 50%、层间可回凡界换构筑再续行；出发前签天道契约（见下）。
  • 四重天界（各入场 20 道源、通关 60）：赤炎天（敌攻+40%、治疗−35%、回合上限32）、万刃天（敌多段连击且血厚）、无生天（治疗−70%、护盾上限25%）、无相天（敌闪避 35~42%、极快）。
  • 天道试炼（各入场 15、通关 45）：七杀（7 连战逐场 ×1.07、场间回三成，记最少总回合）、一线（每场开局 35% 气血、4 战）、无回（治疗完全无效、5 战）。

柒熔炉 · 道痕 · 器魂

  • 天道熔炉：闲置资源换道源——玄铁 25→1、残页 15→1、灵草 60→1、器灵尘 80→1、灵石献祭→5；道源 100 凝 1 枚道果（「此物不随此身而灭」）。
  • 天道变数挑战：入场 18，抽 3 词缀 6 连战（逐场 ×1.06），通关 +55。
  • 虚界之门：花 10 道源生成一个程序化过审世界。
  • 道痕（至多 60 条）：记录每一战——第几世/道途/构筑名/战力/规则纪元/忆战快照。忆战：以当年冻结的构筑重打（无奖励）；重写：花 10 道源以今日之你重打，快过旧痕即「胜于旧我」。旧纪元的痕会标注「天道已变」。
  • 器魂（魂炉）：凡器入天界数值被抹平，凝炼销毁原器 + 20 道源，按词条方向凝成六类器魂——锋（暴击/满血/先手）、盾（护盾/盾伤/减伤）、棘（反击/反伤）、连（连击/连伤/身法）、泽（吸血/回复/溢疗）、背（背水/濒危/处决）；六阶：朦胧→清晰→凝实→通灵→显形→化真（×1.0~2.3）；仅 3 个装配槽，逼迫取舍；无词条白板凝不出器魂。
