关系与阶段

三维关系：缘分 / 信任 / 契合（各 0~100）。阶段门槛：素昧平生 → 萍水相逢 → 相识（缘20）→ 同行（缘35/信20/共历1）→ 知交（缘50/信45/共历2）→ 结契（缘65/信60/契55/共历3）→ 道侣（缘80/信75/契65/共历4）。契合仅在「结契」起成为硬条件。结局四种：相伴终老 / 分道扬镳 / 中道陨落 / 缘悭一面。上一世走到结契以上者，下一世有 8%（上限 35%）概率宿缘重逢。

伍羁绊事件

共同事件（6 个）

只在特定时刻触发（踏入新地界 / 首胜 / 击破首领 / 濒死之际），每种代表一种冲突：遗府（资源——丹方与法宝只够取一样）、刀下（道途——救还是杀）、线索（风险——陪她冒险还是拦住她）、代价（价值观——取药引会令村子薄收三年）、岔路（人生目标——她要离开这条路线）、重伤（共同承担——救你要折损她自己突破用的丹）。选项按道途倾向与你的行为推断道途（杀伐=击杀计数、长生=突破计数、剑心=战斗、丹鼎=炼丹服药、器道=获装分解、问心=学功法奇遇）结算缘分/信任/契合；她也可能当场离开。共同事件不产出任何属性或资源。

她的意图

由经历催生（又一次同行 +0.12、你站在她那边 +0.22、你越过了她的线 −0.3、与她未了之事相关的东西出现 +0.35），受性格阻尼（谨慎 1.35 / 惜物 1.15 / 好奇 0.85 / 激进 0.75）。酝酿满则她自行开口；三种回应：应下（缘+10/信+16/契+6，了结）、回绝（信−8，未了）、不作声（信−4）——忽略不等于回绝，第三次她自己去了（信−14，了结）。
